💻 Programação em C - Exercícios Acadêmicos
Este repositório contém a minha jornada de aprendizado na linguagem C, desenvolvida durante o curso de Ciência da Computação no UniCEUB.

O foco deste projeto é consolidar os fundamentos da computação e lógica através da resolução de listas de exercícios práticos, abrangendo desde operadores básicos até estruturas de repetição e manipulação de dados.

🛠️ Ambiente de Desenvolvimento
Para a realização destes exercícios, utilizei o:

IDE: Code::Blocks

Linguagem: C

📑 Estrutura do Repositório
Os arquivos estão organizados de forma cronológica para facilitar a revisão dos conceitos:

Exercícios Iniciais: Focados em lógica sequencial (entrada e saída de dados).

Estruturas Condicionais: Prática intensiva com if/else e switch.

Laços de Repetição: Resolução de problemas utilizando for, while e do-while.

🚀 Como Executar
Se você também utiliza o Code::Blocks:

Abra o arquivo .c desejado na IDE.

Clique no ícone de Build and Run (F9) para compilar e executar automaticamente.

Caso prefira o terminal (GCC):

Bash
gcc nome_do_exercicio.c -o programa
./programa
